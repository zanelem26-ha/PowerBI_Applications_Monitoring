Application Monitoring — Power BI Report

An interactive Power BI dashboard developed to analyse application health, 
system performance and incidents using monitoring data generated for the Application Monitoring System.

Key areas:

Application health and status overview
Health-check performance and response times
Incident severity and status analysis
Incident trends over time
Application-level performance analysis

Technologies:

Power BI Desktop
DAX
Power Query
Python / Matplotlib
SQL Server

Data

The report uses synthetic/dummy monitoring data created specifically for this portfolio project. 
No production, personal, confidential or real customer data is used.
